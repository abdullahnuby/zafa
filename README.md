# زفّة | ZAFFA

**ZAFFA 0.1.0 — Interactive Arabic RTL PWA prototype**

هذا المستودع يحتوي على حزمة المصدر للإصدار الأول من نموذج زفّة: منصة حجز سيارات الأفراح والمناسبات بسائق، مع إطلاق تجريبي مستهدف في الأقصر.

## استعادة ملفات المشروع

الأرشيف المضغوط موجود مباشرة في:

`releases/zaffa-mvp-0.1.0.tar.xz`

لتجهيز ملفات المشروع داخل جذر المستودع، شغّل سكربت الاستعادة الذي يتحقق من SHA-256 قبل فك الضغط:

**Windows (PowerShell):**

```powershell
powershell -ExecutionPolicy Bypass -File releases/restore.ps1
```

**Linux / macOS:**

```bash
bash releases/restore.sh
```

إذا لم يكن الأرشيف المباشر موجودًا، يعيد السكربت بناءه من الأجزاء الاحتياطية التسعة داخل `releases/zaffa-mvp-parts/` ثم يتحقق من البصمة.

## تشغيل النموذج

يتطلب Node.js 20 أو أحدث:

```bash
npm test
npm start
```

افتح `http://localhost:4173`.

## ما يتضمنه الإصدار

- رحلة العميل: استكشاف السيارات، تفاصيل السيارة، الباقات والإضافات، ملخص السعر، الحجز ومتابعة حالته.
- واجهة المالك: السيارات، التوافر، طلبات الحجز، الأرباح والتسويات.
- واجهة السائق: المهام وتحديث حالات تنفيذ الخدمة.
- لوحة الإدارة: الحجوزات، اعتماد السيارات، الملاك والسائقون، والمالية.
- مسودة PostgreSQL schema وعقد API ووثائق التصميم ونطاق المنتج.
- اختبارات آلية لقواعد الحجز والخادم.

## حدود الإصدار الحالي

هذه **نسخة تفاعلية تجريبية وليست منصة إنتاجية**. بيانات العرض محفوظة محليًا في المتصفح. لم يتم ربط OTP أو مزود دفع أو قاعدة PostgreSQL حية أو إشعارات إنتاجية أو تحقق مستندات حقيقي. السيارات والأسعار المعروضة بيانات توضيحية وليست عروضًا سوقية مؤكدة.

يجب مراجعة مخطط قاعدة البيانات وعقد API، وإضافة قفل توافر ذري على مستوى PostgreSQL، واختبار الأمن والتكاملات، وحسم التراخيص والعقود والتأمين قبل استقبال حجوزات أو مدفوعات حقيقية.
