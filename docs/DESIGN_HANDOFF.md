# ZAFFA Visual Design Handoff

The editable Canva UI concept generated for the product is available here:

- [Open / edit the ZAFFA UI concept](https://canva.link/b54lqzm307ypcu5)

The coded prototype in this repository follows the agreed visual direction: midnight navy, warm ivory, restrained champagne-gold accents, Arabic RTL navigation, spacious cards, and separate customer / owner / driver / admin workspaces.

The prototype is an independent code implementation of the direction; it is not an automatic import of Canva layers. Vehicle artwork in the coded version is illustrative vector art, not the final real vehicle photography. Final production vehicle images must be supplied and approved by their owners.
